This is a program that uses a user uploaded csv reading plan to build a Bible from HelloAO Free Use Bible api. Each chapter represents a day on the reading schedule and contains that days verses. This was entirely coded using Google Gemini. I will not be maintaining or adjusting this further but anyone is welcome to fork and continue working on it. It works for my personal use-case and could potentially help others so I am putting all the files here.

The csv structure is day, reading headings. Readings are comma delineated and can be whole chapters i.e Genesis 1 or broken into verses i.e. Genesis 1:1-17

Use the uploaded csv as a guide.

Download the api.zip here: https://bible.helloao.org/docs/guide/downloads.html
